# dApp marks

Used on the landing page only, as the clutter a stock buy takes today: the apps
someone would otherwise open in their own tabs. They identify those apps and
nothing else; each mark stays its owner's trademark.

Copied on 2026-09-29 from the Ottopus intro films (the Remotion project that
cuts them), where they were gathered from each app's own site. The exact source
URLs were not recorded there, so check each against the app's current brand
kit before anything beyond the landing page uses it.
