# Brand marks

Marks for the companies behind a tokenized stock, so an example on the landing
page reads as that share at a glance. Each stays its owner's trademark and is
used only to name the share.

- `tesla.svg` — the Simple Icons glyph (CC0), white, drawn on Tesla red
  (`#E31937`) by the page. Copied on 2026-09-29 from the Ottopus intro films.
